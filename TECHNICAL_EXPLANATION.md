# DuoLeadPro Technical Assessment Explanation

## Project Overview

This project is a redesigned frontend concept for the DuoLeadPro website, built with Next.js.  
The goal was to create a more modern, structured, and conversion-focused experience while presenting the company's services more clearly and professionally.

The redesign focuses on:

- stronger visual hierarchy
- improved page structure
- clearer service communication
- better user experience across devices
- improved contact and lead-generation flow

---

## Tech Stack

The project was built with:

- Next.js
- React
- JavaScript (JSX)
- Tailwind CSS

Libraries used:

- framer-motion
- lucide-react
- react-hook-form
- zod
- @hookform/resolvers
- embla-carousel-react
- recharts
- clsx
- tailwind-merge
- shadcn/ui

---

## What I Improved

### 1. Homepage redesign

I rebuilt the homepage with a stronger structure and clearer flow.  
The homepage now includes:

- Hero section
- Services overview
- Case studies preview
- Integrations / process section
- FAQ section
- Final CTA

This makes the site feel more complete and helps guide users more effectively.

### 2. Services page

The services page was redesigned to clearly explain the main offerings:

- Global IT & Sales Staffing
- Conversion-Boosting Website Development
- IT Consulting & Scalable Solutions
- Targeted Lead Generation & Marketing

Each service now has:

- a clear heading
- short overview
- detailed explanation
- structured feature list
- clearer business positioning

### 3. Our Web Design page

I added a dedicated page to showcase website projects.  
Each project includes:

- title
- category
- short project description
- image carousel

This helps present previous design directions in a more visual and professional way.

### 4. About page

The About page was expanded to include:

- company story
- team section
- team member photos
- office location
- Google Maps embed
- business hours

This improves trust and gives the brand a more established feel.

### 5. Contact page

The contact experience was improved by adding:

- clickable email link
- clickable phone number
- WhatsApp direct chat
- business address
- business hours
- contact form with service selection

This creates multiple clear contact methods and reduces friction.

### 6. Case studies section

The case studies section was updated to reflect actual showcased website concepts:

- Plumbing Company
- Electric Company
- Painting Company

This keeps the homepage aligned with the project showcase page and makes the design feel more intentional.

### 7. FAQ section

I added a dedicated FAQ section to answer common questions and improve clarity for visitors before they contact the business.

### 8. Integrations / process section

This section was updated to better match the company direction and explain the workflow in a more structured and professional way.

### 9. Service impact chart

A chart section was added to visually communicate expected value and business impact using Recharts.

### 10. Reusable component structure

The site was built using reusable components to keep the code organized and scalable.  
This includes:

- Navbar
- Footer
- Hero
- Services
- CaseStudies
- FAQ
- Integrations
- LeadForm
- ProjectShowcase
- ProjectCarousel
- ServiceImpactChart

## Why I Made These Decisions

The redesign decisions were based on three goals:

### 1. Improve clarity

The original structure left room for clearer communication of the services and company value.  
I reorganized sections and rewrote content to make the offer easier to understand.

### 2. Improve trust

I added stronger trust-building sections such as:

- team section
- office information
- map
- case studies
- FAQ
- multiple contact methods

These make the company feel more credible and established.

### 3. Improve conversion

The redesign includes:

- clearer CTAs
- stronger contact flow
- improved service descriptions
- WhatsApp integration
- structured lead form
- better mobile responsiveness

These changes support lead generation and make it easier for users to take action.

---

## UX / Frontend Considerations

The project was built with attention to:

- responsive layout
- reusable architecture
- modern UI styling
- smooth navigation using Next.js routing
- form validation
- scalable page structure

I also replaced full page reload links with proper Next.js Link navigation where needed for a better user experience.

---

## Content Approach

The content was not copied verbatim from the original website.  
Instead, it was rewritten and restructured to:

- keep the same business meaning
- improve clarity
- improve service positioning
- create a more modern presentation

---

## Conclusion

This redesign is intended to present DuoLeadPro as a more modern, trustworthy, and growth-focused company.  
The goal was not only to improve the visual design, but also to create a stronger frontend structure that supports communication, trust, and conversion.
